# Курсовая работа № 1

## Описание:
Приложение для анализа транзакций, которые находятся в Excel-файле.

## Установка:
1. Клонируйте репозиторий:
```commandline
https://github.com/maks-batsmanov/CourseWork
```
2. Установите зависимости:
```commandline
poetry install
```
## Документация:
### Модуль views содержит код для страницы Главная.
+ Функция main_func объединяет всю логику модулей views и utils.
+ Функцию принимает на вход строку с датой и временем в формате
    YYYY-MM-DD HH:MM:SS и возвращает JSON-ответ.
### Модуль utils содержит вспомогательные функции для модуля views.
+ Функция get_greeting приветствует пользователя
+ Функция read_excel читает excel-файл из папки data, и возвращает датафрейм.
    Принимает на вход имя файла из папки data
+ Функция get_date_interval принимает дату в формате YYYY-MM-DD HH:MM:SS
    возвращает список с двумя датами:
    дата от начала месяца, на который выпадает входящая дата, по входящую дату.
+ Функция selection_by_date принимает dataframe и временной диапазон от начала месяца
    до какого-то дня и возвращает список транзакций из данного диапазона.
+ Функция executed_operations принимает dataframe в указанном диапазоне,
    возвращает только операции со статусом OK.
+ Функция get_amount_by_card принимает dataframe в указанном диапазоне, со статусом OK.
    Возвращает сумму расходов по каждой карте в формате series.
+ Функция get_dict_with_cards принимает series с номерами карт и суммой расходов по ним.
    Возвращает список словарей:
```commandline
[{
      "last_digits": number,
      "total_spent": sum,
      "cashback": cashback
    }]
```
+ Функция get_top_transaction принимает отсортированный по статусу dataframe
    и возвращает топ 5 транзакций по сумме платежа
+ Функция reading_file_user_settings принимает имя json файла из корня проекта, файл содержит валюты для получения обменного курса.
    Читает файл с пользовательскими настройками и возвращает словарь
+ Функция get_exchange_rate принимает словарь с валютами и возвращает обменный курс по валютам. 
    Функция обращается сервису через API.
+ Функция get_stocks принимает имя json-файла из корня проекта,
    файл содержит тикеры акций для получения актуальных цен на бирже.
    Функция возвращает обменный курс по валютам содержащимся в файле.
    Функция обращается сервису через API.
### Модуль reports содержит функции для получения отчета по транзакциям за три месяца от полученной даты.
+ Функция spending_by_category принимает датафрейм, категорию, и опционально, дату.
    Возвращает траты по заданной категории за последние три месяца от переданной даты. 
+ Функция get_time_period принимает DataFrame и дату, возвращает транзакции за три месяца от указанной даты.
+ Функция filtered_by_category принимает Dataframe и категорию, возвращает сумму трат по категории.
+ Декоратор writing_reports записывает результаты вызова функции spending_by_category в файл 'reports_info.txt'
### Модуль services содержит функции для получения суммы которую можно сэкономить при использовании инвесткопилки.
+ Функция investment_bank округляет сумму операции по указанному лимиту.
     Функция принимает три аргумента:
        month — месяц, для которого рассчитывается отложенная сумма (строка в формате 'YYYY-MM').
        transactions — список словарей, содержащий информацию о транзакциях,
    в которых содержатся следующие поля: 'Дата операции', 'Сумма операции'.
        limit — предел, до которого нужно округлять суммы операций.
+ Функция read_json читает json-файл из папки data, и возвращает данные.
        Принимает на вход имя файла из папки data.
### Модуль main объединяет функции проекта
+ Main главная функция, объединяет логику проекта.
+ Функция call_views обращается к модулю views и получает json-ответ.
+ Функция get_report обращается к модулю reports для получения отчета.
+ Функция call_services обращается к модулю services для расчета сэкономленных
    денег с инвесткопилкой
